# Talaria brand

The mark is the **heel wing**: three swept feathers, like the wing on Hermes' sandal.

| File | Use |
|---|---|
| `icon-dark.svg` | App icon, brass wing on night ink |
| `icon-light.svg` | App icon, ink wing on pale paper |
| `mark-ink.svg` | Mark alone, for light backgrounds |
| `mark-brass.svg` | Mark alone, for dark backgrounds |

Colors: ink `#141A33`, brass `#E7B04A`, paper `#F3F5FB`.

This is an early sketch drawn for the project, released under the repo's Apache-2.0 license. A web search for similar winged-feather marks found nothing close, but that is not a trademark clearance. Several unrelated products already use the name "Talaria" (see the project notes), so check the name before any public launch.
